# Анализ отличий готового парсера от текущего

## Основные отличия

### 1. **HTTP-клиент**
- **Готовый парсер**: Использует `curl_cffi` для эмуляции браузера
- **Текущий код**: Использует `httpx`
- **Преимущество**: curl_cffi лучше обходит защиту Cloudflare

### 2. **Система управления cookies**
- **Готовый парсер**: 
  - Абстрактный `CookiesProvider`
  - `ExternalApiCookiesProvider` - покупка cookies через API (spfa.ru)
  - `OwnCookiesProvider` - использование собственных cookies
  - Автоматическая разблокировка cookies
- **Текущий код**: Нет системы управления cookies
- **Преимущество**: Автоматическое обновление при блокировках

### 3. **Система прокси**
- **Готовый парсер**:
  - `NoProxy` - без прокси
  - `ServerProxy` - обычный прокси
  - `MobileProxy` - с автоматической сменой IP
  - Метод `handle_block()` для смены IP при блокировке
- **Текущий код**: Простая поддержка прокси без автосмены IP
- **Преимущество**: Автоматическая смена IP при блокировке

### 4. **Обработка блокировок**
- **Готовый парсер**:
  - Отслеживание кодов 401, 403, 429
  - Счётчик попыток блокировок (`block_threshold`)
  - Автоматический вызов `handle_block()` для cookies и прокси
  - История статус-кодов для умной разблокировки
- **Текущий код**: Базовая обработка ошибок
- **Преимущество**: Умная система восстановления после блокировок

### 5. **Фильтрация объявлений**
- **Готовый парсер**: Модуль `AdsFilter` с цепочкой фильтров:
  - Фильтр просмотренных
  - Фильтр по цене
  - Чёрный список ключевых слов
  - Белый список ключевых слов
  - Фильтр по адресу
  - Фильтр по продавцу
  - Фильтр по времени публикации
  - Фильтр резервов
  - Фильтр продвинутых объявлений
- **Текущий код**: Базовая фильтрация только в `AdsFilter`
- **Преимущество**: Более гибкая и расширяемая система

### 6. **Парсинг JSON со страницы**
- **Готовый парсер**: 
  - Ищет `<script type="mime/invalid" data-mfe-state="true">`
  - Проверяет наличие `i18n.hasMessages`
  - Извлекает `loaderData.data`
- **Текущий код**: Похожая логика, но менее надёжная
- **Преимущество**: Более точная проверка валидности данных

### 7. **Работа с API Avito**
- **Готовый парсер**: 
  - Функция `build_api_params()` для построения параметров
  - Нормализация параметров из searchCore
  - Поддержка пагинации через API
- **Текущий код**: Есть в `utils.py`, но не полностью интегрирована
- **Преимущество**: Полная поддержка всех параметров поиска

### 8. **Определение продвинутых объявлений**
- **Готовый парсер**: Анализ `iva.DateInfoStep` для поиска "Продвинуто"
- **Текущий код**: Не реализовано
- **Преимущество**: Можно фильтровать платные объявления

### 9. **Retry логика**
- **Готовый парсер**:
  - Настраиваемое количество повторов (`max_retries`)
  - Задержка между повторами (`retry_delay`)
  - Автоматическая задержка при блокировке
- **Текущий код**: Базовые повторы в httpx
- **Преимущество**: Более надёжная обработка временных сбоев

### 10. **Архитектура**
- **Готовый парсер**: 
  - Чистая архитектура с разделением ответственности
  - Factory паттерны для создания объектов
  - Абстракции для расширяемости
- **Текущий код**: Более простая структура
- **Преимущество**: Легче добавлять новый функционал
