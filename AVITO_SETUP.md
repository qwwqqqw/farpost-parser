# 🎯 Настройка парсера Avito - Пошаговая инструкция

## Что вам нужно сделать:

### Шаг 1: Открыть Avito и найти нужную категорию

1. Откройте браузер
2. Перейдите на: https://www.avito.ru/rossiya/tehnika
3. Нажмите **F12** (или **Ctrl+Shift+I**) - откроются Developer Tools

### Шаг 2: Найти HTML структуру объявлений

1. В Dev Tools нажмите на кнопку **"Select element"** (стрелка в левом верхнем углу)
2. Наведите на любое объявление на странице и кликните
3. В Dev Tools вы увидите подсвеченный HTML код этого объявления

### Шаг 3: Найти CSS селекторы

Вам нужно найти селекторы для следующих элементов:

#### 3.1. Контейнер объявления
Найдите родительский элемент, который содержит всё объявление.
Обычно это `<div>` с атрибутом `data-marker="item"` или похожим.

**Пример:**
```html
<div data-marker="item" class="iva-item-root-G3n7v">
    <!-- содержимое объявления -->
</div>
```
**Селектор:** `[data-marker="item"]` или `.iva-item-root-G3n7v`

#### 3.2. ID объявления
Найдите атрибут, содержащий уникальный ID объявления.
Обычно это в ссылке или в `data-item-id`.

**Пример:**
```html
<a href="/rossiya/tehnika/noutbuk_2847592834" data-marker="item-title">
```
**ID будет:** `2847592834`

#### 3.3. Заголовок
Найдите элемент с названием объявления.

**Пример:**
```html
<h3 data-marker="item-title">Ноутбук HP</h3>
```
**Селектор:** `[data-marker="item-title"]`

#### 3.4. Цена
Найдите элемент с ценой.

**Пример:**
```html
<span data-marker="item-price">25 000 ₽</span>
```
**Селектор:** `[data-marker="item-price"]`

#### 3.5. Ссылка на объявление
Ссылка обычно в атрибуте `href`.

**Пример:**
```html
<a href="/rossiya/tehnika/noutbuk_2847592834">
```

#### 3.6. Изображение
Найдите тег `<img>` внутри объявления.

**Пример:**
```html
<img src="https://example.com/image.jpg" alt="...">
```

### Шаг 4: Скопировать найденные селекторы

Запишите или скопируйте все найденные селекторы:

```
Контейнер объявления: [data-marker="item"]
Заголовок: [data-marker="item-title"]
Цена: [data-marker="item-price"]
Ссылка: ?
Изображение: ?
Местоположение: ?
Дата публикации: ?
```

### Шаг 5: Передать мне информацию

Пришлите мне:
1. **URL страницы Avito**, которую вы изучали
2. **Список найденных селекторов** (можно скриншот Dev Tools)
3. **Фрагмент HTML** одного объявления (скопируйте из Dev Tools)

## 💡 Подсказки:

### Как скопировать HTML фрагмент:
1. В Dev Tools кликните правой кнопкой на элементе
2. Выберите **Copy** → **Copy outerHTML**

### Что искать в атрибутах:
- `data-marker="..."`
- `data-item-id="..."`
- `class="..."`
- `id="..."`

### Альтернативный способ (простой):

Если сложно - просто:
1. Откройте https://www.avito.ru/rossiya/tehnika
2. Сделайте **скриншот Developer Tools** (F12)
3. Скопируйте **HTML код одного объявления**
4. Пришлите мне

Я сам найду нужные селекторы и обновлю парсер!
