**Проблема:** `RuntimeError('Event loop is closed')`

**Решение:**

- Переработаны синхронные обёртки для async функций
- Добавлена универсальная функция `_run_async()`
- Теперь работает корректно в Windows

**Файлы изменены:**
- [`src/telegram/bot.py`](src/telegram/bot.py)
- [`requirements.txt`](requirements.txt)

### 2. ✅ Проблема с кодировкой emoji в Windows
**Проблема:** `'charmap' codec can't encode character`

**Решение:**
- Убраны emoji из print() в [`main.py`](main.py:78)
- Emoji остались в Telegram сообщениях (там они работают)

Если сайт заказчика - это **НЕ Avito**, то нужно:

1. Создать новый файл: `src/parsers/custom_site_parser.py`

3. Реализовать методы:
   - `get_listings()` - получить список объявлений

   - `_extract_listing_data()` - извлечь данные одного объявления

**Шаблон:**
```python
from src.parsers.base_parser import BaseParser

class CustomSiteParser(BaseParser):
    PLATFORM_NAME = "custom_site"
    BASE_URL = "https://example.com"
    
    def get_listings(self, max_pages: int = 1):
        # Ваша логика
        pass
```

### 2. Использовать API вместо парсинга (если есть)
Многие сайты объявлений имеют API. Это:
- ✅ Быстрее
- ✅ Надёжнее
- ✅ Легальнее
- ✅ Не блокируется

Проверьте, есть ли у сайта заказчика публичный API.

Например, фильтровать по:
- Цене (от X до Y рублей)
