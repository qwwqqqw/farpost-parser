# Farpost Parser с интеграцией в Telegram 


## Основные возможности

- Удобный GUI-интерфейс - настройка всех параметров в одном окне, без редактирования файлов вручную.
- Работа в фоновом режиме (24/7) - парсер работает автономно и уведомляет о появлении новых лотов.
- Уведомления в Telegram - автоматическая отправка найденных объявлений с фото, ценой и ссылкой.
- Прокси -  Поддержка HTTP/HTTPS/SOCKS прокси и обхода защиты анти-бота.
- Встроенные логи -  просмотр вывода работы парсера в реальном времени прямо внутри приложения.
- База данных - исключает повторные отправки ранее увиденных объявлений.

---

## Запуск через готовый `.exe` файл 

Самый простой способ — запустить  файл `Farpost_Parser.exe`.

1. Запустите `Farpost_Parser.exe`.
2. Введите ссылку на нужный раздел Farpost.
3. Заполните Bot Token и Chat ID вашего Telegram-бота.
4. Укажите интервал проверки и прокси (при необходимости).
5. Нажмите кнопку "Сохранить", а затем *"Запуск (Фон 24/7)"** или **"Запуск (Один раз)".

## Запуск из исходного кода

### Требования
- **Python 3.10+**

### Установка и запуск

1. Клонируйте репозиторий или скачайте папку с проектом.
2. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите GUI-приложение:
   ```bash
   python gui.py
   ```
   *(Или используйте CLI-версию через `python main.py once`)*

##  Как просматривать базу данных (SQLite)

Все найденные объявления сохраняются в локальную базу данных SQLite по адресу:
`data/classifieds_parser.db`

Для просмотра содержимого базы данных:

1. **DB Browser for SQLite (Самый удобный способ с графическим интерфейсом)**:
   - Скачайте бесплатную программу [DB Browser for SQLite](https://sqlitebrowser.org/).
   - Откройте программу, нажмите **"Открыть базу данных"** (`Open Database`) и выберите файл `data/classifieds_parser.db`.
   - Перейдите во вкладку **"Данные"** (`Browse Data`), чтобы увидеть таблицу `listings` с прочитанными объявлениями.

2. **Расширение для VS Code / Antigravity IDE**:
   - Установите расширение **"SQLite Viewer"** или **"Database Client"**.
   - Нажмите правой кнопкой мыши по файлу `data/classifieds_parser.db` и выберите **Open with... -> SQLite Viewer**.

## Структура проекта

- `Farpost_Parser.exe` — Исполняемый файл приложения.
- `gui.py` — Исходный код графического интерфейса.
- `main.py` — Точка входа для CLI (консольного режима).
- `src/` — Модули программы (парсинг, база данных, отправка в Telegram, планировщик).
- `data/` — Хранилище базы данных SQLite (`classifieds_parser.db`).
- `logs/` — Лог-файлы работы программы.
- `.env` — Конфигурация с сохраненными настройками.
