# Парсер объявлений - Classifieds Site Scraper

Многоплатформенный парсер для мониторинга новых объявлений на сайтах Avito, Youla и Drom с автоматической отправкой уведомлений в Telegram.

## 🎯 Возможности

- ✅ Парсинг объявлений с Avito, Youla и Drom
- ✅ Отслеживание только новых объявлений
- ✅ Автоматическая отправка уведомлений в Telegram
- ✅ Настраиваемый интервал проверки
- ✅ Работа в фоновом режиме 24/7
- ✅ База данных для хранения объявлений
- ✅ Логирование всех операций
- ✅ Защита от блокировки (задержки, ротация User-Agent)

## 📋 Требования

- Python 3.8 или выше
- Telegram бот (токен от [@BotFather](https://t.me/BotFather))
- Chat ID канала/группы для уведомлений

## 🚀 Установка

### 1. Клонируйте репозиторий или скачайте файлы

```bash
git clone <repository-url>
cd classifieds-site-scraper
```

### 2. Создайте виртуальное окружение

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux/Mac
python3 -m venv venv
source venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Настройте конфигурацию

Скопируйте файл `.env.example` в `.env`:

```bash
# Windows
copy .env.example .env

# Linux/Mac
cp .env.example .env
```

Отредактируйте `.env` файл и заполните необходимые параметры:

```env
# Telegram Configuration
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_CHAT_ID=your_chat_id_here

# Parser Configuration
PARSER_INTERVAL_MINUTES=15
MAX_LISTINGS_PER_RUN=50

# Другие настройки...
```

## 🔧 Настройка Telegram бота

### 1. Создайте бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен бота
4. Скопируйте токен в параметр `TELEGRAM_BOT_TOKEN` в `.env`

### 2. Получите Chat ID

**Для личных сообщений:**
1. Откройте бота [@userinfobot](https://t.me/userinfobot)
2. Отправьте любое сообщение
3. Скопируйте ваш ID в `TELEGRAM_CHAT_ID`

**Для канала:**
1. Добавьте бота в канал как администратора
2. Отправьте любое сообщение в канал
3. Перейдите по ссылке: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
4. Найдите `"chat":{"id":-1001234567890...}` в ответе
5. Скопируйте этот ID (с минусом!) в `TELEGRAM_CHAT_ID`

## 💻 Использование

### Команды

#### Запустить парсер в фоновом режиме (24/7)

```bash
python main.py start
```

Парсер будет работать непрерывно с интервалом, указанным в `PARSER_INTERVAL_MINUTES`.

#### Выполнить парсинг один раз

```bash
python main.py once
```

Полезно для тестирования или ручного запуска.

#### Показать статистику

```bash
python main.py stats
```

Выводит статистику по объявлениям и отправляет её в Telegram.

#### Проверить подключение к Telegram

```bash
python main.py test
```

Проверяет корректность настройки бота и отправляет тестовое сообщение.

## ⚙️ Конфигурация

### Основные параметры в `.env`

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `TELEGRAM_BOT_TOKEN` | Токен Telegram бота | - |
| `TELEGRAM_CHAT_ID` | ID чата для уведомлений | - |
| `PARSER_INTERVAL_MINUTES` | Интервал между проверками (мин) | 15 |
| `MAX_LISTINGS_PER_RUN` | Макс. объявлений за раз | 50 |
| `DATABASE_URL` | URL базы данных | sqlite:///data/classifieds_parser.db |
| `LOG_LEVEL` | Уровень логирования | INFO |
| `AVITO_REGIONS` | Регионы Avito | all |
| `AVITO_CATEGORY` | Категория Avito | tehnika |
| `YOULA_ENABLED` | Включить парсинг Youla | true |
| `DROM_ENABLED` | Включить парсинг Drom | true |
| `USE_PROXY` | Использовать прокси | false |
| `PROXY_URL` | URL прокси-сервера | - |

## 🐛 Отладка

### Проблемы с подключением к Telegram

1. Проверьте токен бота: `python main.py test`
2. Убедитесь, что бот добавлен в канал/группу (если используется)
3. Проверьте правильность Chat ID

### Парсер не находит объявления

1. Структура сайтов может измениться - проверьте селекторы в парсерах
2. Возможна блокировка - попробуйте использовать прокси
3. Проверьте логи в `logs/parser.log`

### Ошибки базы данных

1. Удалите файл базы данных: `rm data/classifieds_parser.db`
2. База будет создана заново при следующем запуске

## 📊 Логирование

Логи сохраняются в директории `logs/`:
- Консольный вывод с цветной подсветкой
- Файл `logs/parser.log` с ротацией (максимум 10 MB)
- Сжатие старых логов
- Хранение логов 30 дней

## 🔒 Безопасность

- Не коммитьте файл `.env` в репозиторий

## ⚠️ Важные замечания

1. **Соблюдайте правила сайтов**: Парсинг должен соответствовать условиям использования целевых сайтов
2. **Избегайте частых запросов**: Используйте разумные интервалы (15+ минут)
3. **Используйте задержки**: Код включает случайные задержки между запросами
4. **Мониторьте изменения**: Структура HTML может измениться, требуя обновления селекторов
