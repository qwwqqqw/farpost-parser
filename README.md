# Farpost Parser с интеграцией в Telegram 

![alt text](Desktop-2026.07.30-12.05.05.02-Trim-_online-video-cutter.com_.gif)

## Основные возможности

- Удобный GUI-интерфейс - настройка всех параметров в одном окне, без редактирования файлов вручную.
- Работа в фоновом режиме (24/7) - парсер работает автономно и уведомляет о появлении новых лотов.
- Уведомления в Telegram - автоматическая отправка найденных объявлений с фото, ценой и ссылкой.
- Прокси -  Поддержка HTTP/HTTPS/SOCKS прокси и обхода защиты анти-бота.
- Встроенные логи -  просмотр вывода работы парсера в реальном времени прямо внутри приложения.
- База данных - исключает повторные отправки ранее увиденных объявлений.

## Запуск через готовый `.exe` файл 

Самый простой способ — запустить  файл `Farpost_Parser.exe`.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/qwwqqqw/farpost-parser.git
   ```
1. Запустите `Farpost Parser.exe`.
2. Введите ссылку на нужный раздел Farpost.
3. Заполните Bot Token и Chat ID вашего Telegram-бота.
4. Укажите интервал проверки и прокси (при необходимости).
5. Нажмите кнопку "Сохранить", а затем *"Запуск (Фон 24/7)"** или **"Запуск (Один раз)".

## Структура проекта

- `Farpost Parser.exe` — Исполняемый файл приложения.
- `gui.py` — Исходный код графического интерфейса.
- `main.py` — Точка входа для CLI (консольного режима).
- `src/` — Модули программы (парсинг, база данных, отправка в Telegram, планировщик).
- `data/` — Хранилище базы данных SQLite.
- `logs/` — Лог-файлы работы программы.
- `.env` — Конфигурация с сохраненными настройками.
