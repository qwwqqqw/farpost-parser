## 📋 Что нужно сделать?

### 1. Установить Python
Убедитесь, что у вас установлен Python 3.8 или новее:
```bash
python --version
```

### 2. Создать виртуальное окружение
```bash
# В директории проекта выполните:
python -m venv venv

# Активируйте окружение:
venv\Scripts\activate
```

### 3. Установить зависимости
```bash
pip install -r requirements.txt
```

### 4. Настроить Telegram бота

#### Создать бота:
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен бота

#### Получить Chat ID:
- **Для личных сообщений:** [@userinfobot](https://t.me/userinfobot)
- **Для канала:** Добавьте бота в канал как администратора, затем перейдите:
  ```
  https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
  ```
  Найдите `"chat":{"id":-1001234567890}` и скопируйте ID

### 5. Создать .env файл
```bash
# Скопируйте пример:
copy .env.example .env

# Откройте .env в редакторе и заполните:
```

**Минимальные настройки:**
```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
TELEGRAM_CHAT_ID=ваш_chat_id
```

**Дополнительные настройки (опционально):**
```env
PARSER_INTERVAL_MINUTES=15
MAX_LISTINGS_PER_RUN=50
AVITO_ENABLED=true
YOULA_ENABLED=true
DROM_ENABLED=false
```

### 6. Проверить подключение
```bash
python main.py test
```

Вы должны увидеть:
```
✅ Подключение к Telegram успешно!
✅ Тестовое сообщение отправлено!
```

### 7. Запустить парсер

**Тестовый запуск (один раз):**
```bash
python main.py once
```

**Постоянная работа (24/7):**
```bash
python main.py start
```

**Остановка:** Нажмите `Ctrl+C`

## 🔧 Возможные проблемы

### ❌ Ошибка: "No module named 'src'"
**Решение:** Убедитесь, что вы находитесь в директории проекта и виртуальное окружение активировано.

### ❌ Парсер не находит объявления
**Решение:** 
- Структура сайтов может измениться
- Проверьте логи: `logs/parser.log`
- Попробуйте использовать прокси

### ❌ Telegram не отправляет сообщения
**Решение:**
- Проверьте токен и Chat ID
- Запустите: `python main.py test`
- Убедитесь, что бот добавлен в канал (для каналов)
